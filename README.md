スマートフォン片手操作に最適化した、遊戯王マスターデュエルのランクマッチ高速記録＆多角分析Webアプリケーションです。

## ✨ 主な機能と特徴

### 1. 📱 スマホ片手で3秒記録
- **コイントス ＆ 先攻/後攻 ＆ 勝敗** を大型セグメントボタンでワンタップ入力。
- 「コイントス裏なのに相手が先攻を渡してきた」ケースも **「🎯 相手が後攻選択（先攻渡し）」** として正確に自動判定。
- **「早期見切り(即サレ)」** ➔ 自動で `Lose` ＆ カウンター結果を **「未展開(即サレ)」** にスマート連動（相手即サレは `Win`）。

### 2. 📸 遊戯王ニューロンのデッキリスト（JPG / PDF）からAI自動構造化
- 遊戯王ニューロンから出力したデッキレシピシート（**JPG画像またはPDF**）をアップロードするだけで、**Gemini 2.5 Flash Vision がモンスター/魔法/罠/EXのカード名と枚数を自動テキスト化**。
- 枚数の微調整（`＋` / `－` ボタン）やテキスト一括編集にも対応。
- **自軍妨害の自動連動**: 使用デッキに登録された採用カード（うらら、増G、泡影、リトルナイト、テーマ固有罠など）が、対戦記録画面の最上段に専用チップとして自動ピン留めされます。

### 3. 📊 戦績ダッシュボード ＆ 5大統計アナリティクス
- **ダッシュボード**: 日次・月次（ランクマシーズン）・全期間の切り替え対応。
  - 総対戦数（連勝/連敗バッジ）/ 勝率 / 先攻勝率 / 後攻勝率 / コイン勝率 / 先攻率（先攻渡し内訳）の6大指標。
- **5大統計アナリティクス**:
  1. **対面相性**: 環境デッキ別の遭遇数・総合勝率・先後別勝率ランキング。
  2. **自デッキ分析**: 構築ごとの勝率・初動○率（初動安定度）・先後別勝率。
  3. **貫通・ケア展開分析**: 「対抗札貫通」「ケア展開で回避」「妥協盤面」「停止」別の発生回数と実際の勝率。
  4. **誘発・妨害分析**: 自分が撃ったカードの「勝利貢献度」＆ 相手に撃たれたカードの「被弾時勝率（弱点分析）」。
  5. **主因・判断・ストレス相関**: プレミや判断迷い、ストレス高（Lv.4〜5）の試合での勝率低下を可視化。

### 4. 🤖 AI伴走コーチング ＆ 🛑 3連敗ストッパー
- 記録完了時に、Gemini 2.5 Flash が試合内容（使用デッキ・誘発応酬・勝因・ストレス度）を汲み取った100文字戦評を即座にフィードバック。
- 3連敗時や高ストレス連続時には、**赤いストッパー警告モーダル** が立ち上がり、メンタル崩壊による溶かしを防ぐための休憩を促します。

## 🚀 誰でも5分で使える！自分専用スプレッドシート連携手順

本アプリは **「完全分散型（サーバーレス）」** アーキテクチャを採用しています。  
GitHub Pages（画面）は共通ですが、**データは各自のGoogle スプレッドシートにのみ保存されます**（開発者や第三者にあなたの対戦データが見られることは一切ありません。費用も完全無料です）。

### STEP 1: スプレッドシートを新規作成
1. ブラウザで [Google スプレッドシート (sheets.new)](https://sheets.new) を開き、新しい白紙のスプレッドシートを作成します。
2. シートのタイトルを適当に入力します（例: `マスターデュエル対戦記録DB`）。

### STEP 2: GASスクリプトを貼り付ける
1. スプレッドシートのメニューバーから **「拡張機能」➔「Apps Script」** を開きます。
2. エディタ内の初期コード（`function myFunction() {}`）をすべて消去します。
3. 本リポジトリの **[`gas/Code.gs`](file:///c:/Users/user/Documents/md_logger/gas/Code.gs)** のコードをすべてコピーし、エディタに貼り付けて **保存（Ctrl + S / Cmd + S）** します。

### STEP 3: ワンクリック初期セットアップを実行
1. スプレッドシートの画面に戻り、ページを再読み込み（F5）します。
2. メニューバーの右端に **「🏆 MDロガー」** というメニューが追加されるので、**「✨ 初期シート自動生成・セットアップ」** をクリックします。
   - ※初回のみ「承認が必要です」と出るので、画面の指示に従って「詳細」➔「〇〇に移動」➔「許可」を押してください。
3. 実行すると、『対戦ログ』『マスタ設定』『デッキレシピ』の3シートと環境マスタが自動生成されます！

### STEP 4: WebアプリとしてデプロイしてURLを取得
1. Apps Script エディタの画面右上にある青い **「デプロイ」➔「新しいデプロイ」** をクリックします。
2. 歯車アイコンをクリックし、**「ウェブアプリ」** を選択します。
3. 以下の設定になっていることを確認します：
   - **次のユーザーとして実行**: **`自分`**
   - **アクセスできるユーザー**: **`全員`**（※ここを「全員」にしないとスマホから書き込めません）
4. **「デプロイ」** を押し、発行された **ウェブアプリのURL (`https://script.google.com/macros/s/.../exec`)** をコピーします。

> **💡 オプション（AI伴走コメントを有効化する場合）**:  
> Apps Script の「プロジェクトの設定（歯車アイコン）」➔「スクリプト プロパティ」に、プロパティ名 `GEMINI_API_KEY`、値に [Google AI Studio](https://aistudio.google.com/) で取得した無料APIキーを設定してください（設定しなくても定型アドバイスで正常に動作します）。

### STEP 5: スマホアプリの「API設定」に貼るだけ！
1. スマホで **https://makibanoasa.github.io/md_logger/** を開きます。
2. 右上の **「⚙️ API設定」** をタップし、先ほどコピーしたURLを貼り付けて **「保存して反映」** を押します。
3. 上部に緑色で **`GAS連携中`** と表示されれば連携完了です！

## 📲 スマホでアプリ化する（PWAインストール）

### Android (Google Chrome)
1. Chrome で https://makibanoasa.github.io/md_logger/ を開きます。
2. 右上のメニュー（`︙`）をタップし、**「アプリをインストール」** または **「ホーム画面に追加」** を選択します。

### iPhone / iPad (Safari)
1. Safari で https://makibanoasa.github.io/md_logger/ を開きます。
2. 画面下部中央の **共有ボタン（四角から矢印が出ているアイコン）** をタップします。
3. 少し下にスクロールして **「ホーム画面に追加」** を選択します。

ホーム画面に追加されたアプリアイコンから起動すると、ブラウザのアドレスバーが消え、全画面のネイティブアプリとして快適に動作します。
